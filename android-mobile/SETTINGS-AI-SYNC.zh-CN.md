# 桌面提示词、Skills 与手机设置（2026-11-02）

用户要求同步精调的系统提示词与 skills、接完整模型切换链路，并做独立设置页。当前基线为 main / `7aca818cad68a4d90cc8daad9a11816e3d875351` 的既有工作树；桌面 2.0.0-preview.1，安卓升级为 0.5.0-pilot.5。本轮沿用 MIG-002/003/030，不把产品迁移差集新增为 AUD 漏洞。此前“领域 Skills 未迁”的结论描述 0.4 阶段，后续状态以此记录为准。

## 同步内容

构建脚本直接读取桌面原声明，编译同步以下内容，而非手工维护另一份缩短提示词：工作台承接规则、初学者执行规则、托管下载/制作规则、按需 skill 策略、应用保护、图片/模型回复约定、当前连接的身份/模型规则、模组及整合包工作台上下文与 Fabric 版本分支。包含已有 Fabric API 内嵌与运行证据等精调规则。模型身份在每轮执行时替换成真实解析到的连接标识，避免续聊沿用旧模型名。

桌面内置17类 skill 原文和参考文件，共48文件、145480 bytes（约142 KiB），全部打进运行包。当前桌面 AI 资源指纹为 `8b32286d248f66ead7bb4316a7c9e2d8eb0e23d3e2d22712b62ed6cdbf989b78`。设置可查看原文，AI 通过新增的 `modmind_mobile_skills` list/read 按当前模式读取 skill 和其相对路径参考文件；没有批量把全部正文塞进每轮消息，也不需要开放任意 shell。

当前具备手机执行基础的七类列为可用候选：模组开发、构建修复、内容资源、整合包制作、图像、建模、灵感整理；每轮还按模组/整合包、工作台/灵感台筛选。其余十类原文保留在设置的折叠列表，标明手机能力未接或用户暂缓，不开放给 AI 误用。某类 skill 可读取不等于它提到的所有桌面工具都已迁移。手机覆盖规则明确映射已接工具、只读和构建边界，暂不支持的步骤如实说明；灵感结构化提交、完整 Blockbench、发布/游戏运行等缺口继续保留。

自定义 skill 复用桌面 UserSkillStore 的 YAML 校验、revision 冲突、参考文件读取和启停语义，手机可新建/粘贴、编辑、启用/停用与确认移除；最多64个，每份正文256 KiB。目录/ZIP及参考文件的手机系统选择器导入仍未接，不能称为完整桌面导入器。本次只读核对本机 `%APPDATA%/modmind/workbench-skills` 为0个，settings.json 没有另存的自定义系统提示词字段，精调原文来自仓库。不会把开发本应用使用的 Codex/.agents 通用技能误作产品领域技能同步。

## 模型切换

复用桌面 ProviderSyncService：目录、供应商、免费/额度计费、付费组、不可用状态、选择回执、路由重新核对和执行前 resolve。自定义文字 API 沿用模型目录检查和私有密钥保存。设置增加“全局默认 / 工作台 / 灵感台”选择范围；两个会话面可独立绑定并恢复跟随全局，输入框显示其实际选择。全局选择按桌面规则清除面绑定；任务运行中要求先停止后切换，不承诺在已经发出的推理请求中途更换模型。

思考强度按原值发送；可编辑1–5个候选档位，自动时不发送强度覆盖。上下文、压缩阈值和思考档位按精确模型与线路保存，复用桌面模型预算、90%阈值校验和原生 model catalog 生成；配置进入手机 Codex 的实际调用。切换模型时按桌面策略回到自动推理。Fast 复用账号设备接口，仅支持允许切换的付费线路；免费/自定义/LS等未支持的线路禁用，未把保存布尔值冒充生效。

## 设置逐项对照

独立设置从项目菜单进入，可搜索；聊天主入口仍只有工作台和灵感台。模型快捷入口打开设置中的当前会话面选择。以下表按桌面 settingsDefinitions 的分区逐项对照，未实现处不伪造可用开关。

| 桌面分区 | 手机结果 | 边界 |
| --- | --- | --- |
| 外观 | 跟随系统/浅深、五种主题、强调色、字号80–125%、思考折叠偏好 | 使用系统字体和原生 WebView 文本缩放；媒体背景未接，自定义背景色保留数据但界面仅调强调色 |
| 侧栏编辑/排序 | 两主入口与项目菜单的手机布局 | 没有桌面侧栏，未照搬排序器 |
| 通知/关闭窗口 | Android前台环境通知；可申请AI任务完成通知权限 | 完成通知当前由对话运行状态触发，后台长驻/所有构建通知未完整验证；窗口/托盘由系统代替 |

| Java | 内置JDK21与项目Wrapper、构建内存512–4096MiB | 不复制电脑JAVA_HOME/可执行路径，不支持切换另一套手机JDK |

| 网络 | 应用HTTP(S)代理经现有网络服务，Gradle/JVM有HTTP代理参数 | 未实测真实代理；JVM的HTTPS代理端点兼容性不作保证，不复制电脑127.0.0.1代理 |
